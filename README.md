# Reac# 📈 Calculadora de Interés Compuesto

Aplicación frontend desarrollada con React + TypeScript para calcular el crecimiento de una inversión a lo largo del tiempo aplicando la fórmula de interés compuesto. Ideal para practicar manejo de formularios, lógica matemática y visualización de resultados.

---

## 🧩 Descripción general

Esta app permite:

- 💰 Ingresar monto inicial, tasa de interés, período y frecuencia de capitalización  
- 📊 Calcular el monto final acumulado con interés compuesto  
- 📈 Visualizar resultados de forma clara y responsiva  
- 🧠 Practicar lógica matemática y manejo de estado en React  
- 🧼 Aplicar buenas prácticas de diseño y modularización  

---

## ⚙️ Tecnologías utilizadas

### Frontend

- ⚛️ React + TypeScript  
- ⚡ Vite como entorno de desarrollo  
- 🎨 Tailwind CSS para estilos rápidos y responsivos  
- 📦 Componentes organizados por lógica y presentación  
- 🧠 Estado con `useState` y validación de entradas
